# 决策：行为克隆——从真人录制的鼠标数据里学，而不是拍参数

Status: implemented

## 问题

鼠标“像人”这件事没有客观判据。作者的做法是把曲线封在 `csystem.dll` 里（实测是
smoothstep 直线加抖动）；我们也写过参数化版本（贝塞尔路径、余弦钟形速度、高斯落点），
但“参数看起来像人”和“统计上像人”是两件事，缺一个能拿数字说话的判据。

## 决定

三层，按代价从低到高叠，每一层都能独立拿来用：

**轨迹模板复用。** 真人录制的每次移动归一化成「沿程/法向」的单位曲线，新目标按距离比例
挑最相近的一条，旋转缩放后重放。碎步、末端微调都是真人自带的，不需要我们参数化。
实现在 [`src/hspy/clone.py`](../../src/hspy/clone.py)。

**参数分布。** 按下时长、思考时间、局间间隔直接从真人样本采样（对数正态/双峰），
不拍一个固定值。实现在 [`src/hspy/humanize.py`](../../src/hspy/humanize.py)。

**判别器。** 切 30 秒窗口提特征，训分类器区分真人与脚本，用 AUC 和「整体偏差」评分。
实现在 [`scripts/train_discriminator.py`](../../scripts/train_discriminator.py)。

## 后果

实测（2026-10-27，9 分钟真人录制，19808 事件 / 544 秒）：

```
真人        每秒 36.4、每步 4.0px、弯曲度 0.324、按下 104ms / p90 296ms
模板克隆    每秒 55.6、每步 6.1px、弯曲度 0.249、按下 125ms / p90 274ms   整体偏差 0.77
神经生成    整体偏差 1.14
旧参数脚本  每秒 8.1、每步 15.3px、弯曲度 0.009、按下 21ms              整体偏差 1.65
```

结论是模板克隆优于神经生成，神经生成优于参数化。这些数字都能复算，但**样本本身没有入库**：原始录制在 `test/human1`、克隆样本在 `test/clone1`，命令是
`python -X utf8 scripts/train_discriminator.py --human test\human1 --generator clone=test\clone1`；模板库是 `data/move_templates.json`（430 KB，102 条模板 / 213 个按下样本），由 `python -X utf8 scripts/extract_moves.py` 从真人录制里抽出来。神经版（距离 → 16 个路点）训练集
R² 只有 0.07，说明轨迹形状与距离基本无关，小样本下不值得上模型——这条也写进了
[0006 之外的实现判断](../../scripts/lstm_move.py)。

代价有三个。需要真人数据，至少十分钟、几百次点击，换人或换卡组要重录；模板库是文件
（`data/move_templates.json`），要跟着代码一起更新；判别器在小样本下 AUC 一律虚高到
1.000，只能看「整体偏差」，不能当验收硬指标。

**没选的路**：直接上 LSTM/VAE 生成轨迹，样本量不够时模型会坍缩到平均路径（实测 8 条
生成轨迹几乎一样）；以及继续手调参数，那是我们已经走过的路，偏差 1.65 就是它的上限。
