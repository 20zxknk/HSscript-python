# 缺陷看板

这一页是给 Obsidian 用的**实时视图**：读的是每条 bug README 顶部的 front-matter，
不用跑 `scripts/build_docs.py`，改完 README 这里立刻变。

> 依赖社区插件 **Dataview**（已装好并启用）。纯文本版台账见 `docs/bugs-index.md`。

## 待修（state = 未修）

```dataview
TABLE id AS 编号, module AS 模块, root_cause AS 根因, reopened_count AS 重开
FROM "bugs"
WHERE state = "未修"
SORT reopened_count DESC, id ASC
```

## 复发过的（reopened_count > 0）

```dataview
TABLE id AS 编号, state AS 状态, reopened_count AS 重开, root_cause AS 根因
FROM "bugs"
WHERE reopened_count > 0
SORT reopened_count DESC
```

## 按代码位置分组（module）

```dataview
TABLE rows.id AS 条目, rows.state AS 状态
FROM "bugs"
GROUP BY module
SORT length(rows) DESC
```

## 还标着「实机验证」的

```dataview
TABLE id AS 编号, verify.build AS 构建, verify.logs AS 证据
FROM "bugs"
WHERE state = "已修（实机验证）"
SORT id ASC
```

## 全部条目（按编号）

```dataview
TABLE id AS 编号, state AS 状态, module AS 模块, stage AS 阶段
FROM "bugs"
SORT id ASC
```
